# Requirements

This folder holds the detailed requirements. Platform requirements sit at the top of the folder, and each game has its own folder:

| File | Contents |
| --- | --- |
| `platform.md` | Dashboard, multi-game support, hosting, and self-hosting |
| `number-game/rules.md` | Board, matching, line of sight, row removal, adding numbers, stages, scoring, and game over |
| `number-game/difficulty.md` | Difficulty presets and ideas for later |
| `block-game/rules.md` | Board, hands, shapes, the fair deal, placing, line clearing, scoring, and game over |
| `survivor-game/rules.md` | Rooms, movement, the rope, shooting, enemies, upgrades, scoring, and defeat |
| `survivor-game/balance.md` | The numbers the Survivor Game rules use |
| `players-saves-scores.md` | Player IDs, server save slots, and high scores |
| `open-questions.md` | Open decisions, the chosen tech stack, and answered questions |
| `BACKLOG.md` | Known gaps and ideas that are not planned as tasks yet |
